# Research Questions

The purpose of VSM-1 is not to prove viability.

The purpose is to identify constraints.

This repository currently treats the following questions as primary.

---

# 1. Film Stability Problem

Question:

Can continuous thin films remain stable across large vertical surfaces?

Unknowns:

* minimum wetting rate
* rivulet formation
* sheet height limits
* thermal gradient effects

Failure condition:

```text
Film Collapse

↓

Dry Regions

↓

Surface Area Loss

↓

Performance Collapse
```

---

# 2. Biological Colonization Problem

Question:

How rapidly do biological systems degrade evaporative sheet performance?

Unknowns:

* biofilm growth rate
* roughness changes
* wetting degradation
* cleaning frequency

Failure condition:

```text
Biofilm Growth

↓

Pressure Drop Increase

↓

Reduced Mass Transfer
```

---

# 3. Economic Breakeven Problem

Question:

Does purification complexity eliminate aerodynamic gains?

Unknowns:

* capital intensity

Failure condition:

```text
Complexity Cost

>

Operational Benefit
```

# Core Repository Question

The central hypothesis of VSM-1:

> Can extreme fluid purification unlock evaporative operating regimes that are impractical under conventional chemistry constraints?

The repository exists to determine whether the answer is:

```text
Yes

No

Or Only Sometimes
```
